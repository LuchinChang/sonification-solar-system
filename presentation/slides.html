Contributions

C1 · Paradigm

The Sonification Playground

A rule-based, two-sided design framework. Data-side rules say what becomes a signal; sound-side rules say what dimensions receive it. Specific mappings are searchable instances within the rules — not hand-crafted artifacts.

C2 · Instantiation

Planetary Link-Line System

A live, browser-based system that applies the paradigm to planetary link-line geometry. Geometric probes (sweepers, shapes) trigger sound; output is live-coded Strudel — human-readable and machine-parseable.

Tech stack

TypeScript Vite HTML5 Canvas @strudel/core @strudel/webaudio @strudel/mini

Rendering: Canvas-based render loop on requestAnimationFrame; orbital lines pre-computed.

Audio: Live-coded Strudel patterns concatenated per probe, evaluated via the Strudel REPL through the Web Audio API.

Node editor: Custom 13-file subsystem with deferred-commit semantics — cable drags mutate the graph in memory; Strudel re-evaluates only on panel close or Ctrl+Enter.
